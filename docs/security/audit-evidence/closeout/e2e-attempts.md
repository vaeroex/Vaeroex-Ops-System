# Preserved qualification attempts

Attempts1–2 exposed harness selector/wait errors (native details/summary drawer, streamed pagination). Attempt3 proved persisted desktop/mobile form and memory writes but reloaded manually; it did not prove automatic action navigation. Its premature assertion read a still-streaming source page; one React418 hydration error was also observed and is retained as an unresolved intermittent observation. Independent settled GET/action controls did not reproduce that error. Attempt4 waited for the actual automatic action redirect and failed: the record persisted but the page remained pending. The navigation-diagnosis directory narrows that failure without claiming a root cause or production impact. Later tests must explicitly distinguish automatic completion from manual-recovery continuation; earlier failures are not erased by a passing narrower test.
